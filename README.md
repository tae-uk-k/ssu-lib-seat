# 도서관 좌석 예약 (숭실대 중앙도서관)

원하는 좌석을 골라 두면, 그중 한 자리가 비는 순간 자동으로 예약해 주는 앱이에요. 안드로이드 폰, Windows, macOS에서 쓸 수 있어요.
서버 없이 내 기기에서 도서관 사이트(oasis.ssu.ac.kr)로 직접 요청을 보내요.

> 학교나 도서관과 관계없는 비공식 앱이에요. 도서관 사이트가 바뀌면 동작하지 않을 수 있고,
> 사용에 따른 책임은 사용자에게 있어요. 도서관 이용 규정을 꼭 확인하세요.
> 앱 아이콘의 숭실대학교 심볼은 학교의 상징이며 권리는 학교에 있어요. 학교의 공식 앱이라는 뜻이 아니에요.

## 설치

[최신 릴리스](https://github.com/tae-uk-k/ssu-lib-seat/releases/latest)에서 쓰는 기기에 맞는 파일을 내려받아요.

### 안드로이드 폰 (`ssu-lib-seat-*.apk`)

1. 폰 브라우저에서 `.apk` 파일을 내려받아요.
2. 파일을 열면 "알 수 없는 앱 설치" 허용을 물어봐요. 브라우저(또는 파일 앱)에 허용하고 설치해요.
3. 설치 후 알림 권한을 허용해 주세요. 백그라운드에서 돌 때 필요해요.

### Windows (`ssu-lib-seat-*-windows.zip`)

1. 압축을 원하는 폴더에 풀어요. (압축 파일 안에서 바로 실행하면 안 돼요.)
2. `ssu_lib_seat.exe`를 실행해요.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 눌러요. 서명하지 않은 프로그램이라 처음 한 번 나오는 안내예요.

### macOS (`ssu-lib-seat-*-macos.zip`)

1. 압축을 풀어 나온 앱을 "응용 프로그램" 폴더로 옮겨요.
2. 처음 실행하면 "확인되지 않은 개발자" 안내가 떠요. 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 눌러요.
   그래도 안 열리면 터미널에서 `xattr -dr com.apple.quarantine /Applications/SsuLibSeat.app`을 실행한 뒤 다시 열어요.
3. 알림 허용 창이 뜨면 **허용**을 눌러요. 예약이 끝났다는 알림을 받으려면 필요해요.

### 컴퓨터에서 쓸 때 알아둘 점

- 예약이 끝나면(배정 완료, 중단 등) **컴퓨터 알림**으로 알려 줘요.
- 예약하는 동안 컴퓨터가 잠자기에 들어가지 않아요. 창을 최소화하거나 다른 창에 가려도 계속 돌아요.
- **예약이 도는 동안 창을 닫으면 예약도 멈춰요.**
- 새 버전이 있으면 앱 맨 위에 안내가 떠요. **Windows는 "업데이트" 버튼을 누르면 앱이 스스로 새 버전을 내려받아 바꾸고 다시 켜져요.** (예약이 도는 중에는 할 수 없어요. 앱이 `C:\Program Files`처럼 쓸 수 없는 폴더에 있으면 다운로드 페이지가 열려요.) macOS는 다운로드 페이지를 열어 줘요.

## 사용법

1. **로그인** — 도서관 홈페이지와 같은 학번/비밀번호를 넣어요. 폰 안에 암호화해서 저장하고, 어디로도 보내지 않아요. 저장해 두면 앱을 켤 때 한 번 자동으로 로그인해요. 저장된 계정이 거절되면 계정이 잠기지 않도록 자동 로그인을 멈추고, 직접 로그인해야 해요.
2. **열람실 선택** — 이용 가능한 좌석 수가 보이는 열람실 카드를 눌러요.
3. **좌석 선택** — "도면에서 좌석 고르기"를 눌러 도면을 크게 열고 좌석을 골라요. 먼저 고른 좌석이 우선순위예요(좌석에 번호가 붙어요). 고른 좌석을 모두 지우려면 도면 위쪽의 "모두 해제"를 눌러요.
4. **예약 시작** — 화면을 꺼도 계속 확인하다가, 선택한 좌석이 비면 바로 예약해요.

왼쪽 위 **메뉴(☰)** 에 내 좌석(자동 연장 켜고 끄기), 진행 기록, 확인 간격, 배터리 제한, 업데이트 확인, 오류 기록이 모여 있어요.

### 자동 연장

**자동 연장**이 켜져 있으면(기본값), 내 좌석의 **이용 종료 30분 전부터 자동으로 연장**해요. 좌석을 받은 뒤에도 앱이 계속 지켜봐요.

- 도서관 밖이라 연장이 안 되면 **5분 뒤에 다시 시도**해요. 남은 시간이 있는 동안 계속해요. 첫 실패는 알림으로 알려 주고, 연장되면 알림으로 알려 줘요.
- 이미 좌석이 있다면 좌석을 고르지 않고 **"자동 연장만 시작"** 을 눌러도 돼요.
- 메뉴의 **내 좌석**에서 지금 갖고 있는 좌석과 남은 시간, 자동 연장 스위치, **지금 연장이 동작하고 있는지**를 볼 수 있어요. 켜 두기만 해서는 동작하지 않고, 예약을 시작하거나 "자동 연장만 시작"을 눌러야 해요. (좌석이 있을 때 이 화면에서 스위치를 켜면 바로 동작해요. 도는 중에 켜고 꺼도 바로 적용돼요.)
- 같은 **내 좌석** 화면의 **"반납하기"** 버튼으로 좌석을 바로 반납할 수 있어요 (아직 이용을 시작하기 전이면 "배정 취소하기"). 되돌릴 수 없어서 누르면 한 번 더 물어봐요. 반납하면 자동 연장도 함께 끝나요.
- 앱이 한 일(로그인, 예약, 연장, 업데이트, 오류)은 메뉴의 **진행 기록**에 시각과 함께 남고, 복사하거나 지울 수 있어요. 앱을 껐다 켜도 지난 기록이 남아 있어요.
- 연장 횟수에는 도서관이 정한 제한이 있어요. 제한을 넘으면 서버가 거절해요.

### 이미 좌석이 있을 때 (좌석 바꾸기)

예약을 시작할 때 이미 좌석이 있으면 "N번 좌석을 반납하고 바꿀까요?"라고 **한 번 물어봐요.** "바꾸기"를 누르면, 선택한 좌석이 나는 순간 내 좌석을 **반납하고** 새 좌석을 예약해요. (아직 확정 전인 좌석은 취소, 이용 중인 좌석은 반납으로 처리돼요.) 좌석이 없으면 묻지 않아요.

- 선택 목록에 내 좌석이 있으면, 그 좌석보다 **먼저 고른** 좌석이 날 때만 바꿔요. 가장 먼저 고른 좌석을 이미 갖고 있으면 거기서 멈춰요.
- 반납한 뒤 새 예약이 거절되면 원래 좌석을 다시 예약해 봐요. 이용 중이던 좌석은 이용 시간이 새로 시작되고 도착 확인을 다시 해야 할 수 있어요. 그것도 안 되면 좌석이 없어질 수 있으니 알림을 꼭 확인해 주세요.

### 확인 간격

고른 좌석이 곧 비면 설정한 간격(기본 1.5초)으로 자주, 한참 남았으면 뜸하게 확인해요. 고른 좌석 중 가장 먼저 끝나는 좌석의 남은 시간이 기준이에요.

| 남은 시간 | 확인 간격 |
| --- | --- |
| 3분 이하 | 설정한 간격 (가장 빠름) |
| 10분 이하 | 3초 |
| 30분 이하 | 6초 |
| 60분 이하 | 15초 |
| 그보다 많음 | 30초 |

이미 빈 좌석이 있거나 남은 시간을 모르는 좌석이 있으면 늘 설정한 간격으로 확인해요. 남은 시간은 "최대"라서 그전에 퇴실해 일찍 비는 좌석은 조금 늦게 발견될 수 있어요.

## 업데이트

앱을 켤 때 새 버전이 있는지 확인해서(새 버전이 없었다면 6시간 안에는 다시 묻지 않아요), 있으면 맨 위에 **업데이트** 버튼이 나와요. 메뉴의 "업데이트 확인"으로 직접 확인할 수도 있어요.
누르면 내려받아 설치 창이 열려요. 예약이 도는 중에는 업데이트할 수 없어요 (설치하면 앱이 다시 시작돼요).

## 알아둘 점

- 로그인을 여러 번 틀리면 계정이 잠길 수 있어서, 앱은 로그인이 틀리면 **재시도 없이 바로 멈춰요**.
- 확인 간격은 최소 1초예요. 서버에 부담을 주지 않도록 더 짧게는 못 해요.
- **최근 앱 목록에서 앱을 밀어서 끄면 예약도 멈춰요.** 홈 화면으로 나가는 건 괜찮아요. 멈췄다면 다음에 앱을 켤 때 "지난 예약이 중간에 멈췄어요"라고 알려 줘요.
- 예약이 끝나면(배정 완료, 서버 문제, 예약 거절 등) 앱이 백그라운드에 있어도 알림으로 알려 줘요. 알림 권한을 허용해 주세요.
- 서버가 잠깐 이상해도(점검, 연결 끊김) 예약은 멈추지 않고 간격을 늘려 가며 다시 시도해요. 2시간 넘게 계속되면 멈추고 알려 줘요.
- 폰 제조사 설정(배터리 최적화, "절전 앱")이 백그라운드 앱을 끊을 수 있어요. 앱을 처음 켜면 배터리 제한을 풀어 달라는 안내가 한 번 떠요. 놓쳤다면 메뉴의 "배터리 제한 → 제한 풀기"를 누르거나, 폰 설정 → 앱 → 이 앱 → 배터리에서 "제한 없음"으로 바꿔 주세요.

## 개발자용

```bash
flutter pub get
flutter analyze && flutter test
flutter build apk --release      # 안드로이드
flutter build windows --release  # Windows (Windows PC 에서만)
flutter build macos --release    # macOS (맥에서만)
```

Windows 빌드에는 Visual Studio 의 "C++를 사용한 데스크톱 개발"과 **Windows 개발자 모드**(설정 → 시스템 → 개발자용)가 필요해요.
플러그인을 연결할 때 심볼릭 링크를 쓰기 때문이에요. macOS 앱은 맥과 Xcode 가 있어야 만들 수 있어서, 릴리스하면 GitHub Actions(`.github/workflows/macos.yml`)가 대신 만들어 릴리스에 붙여요.

### 릴리스 (앱 안 업데이트로 배포)

```bash
python tools/release.py "이번 변경 내용 한 줄"
```

버전 올리기(`1.0.N+N`) → 분석/테스트 → 서명 빌드 → 서명 키 확인 → Windows 프로그램 빌드·압축 → 커밋·태그·푸시 → GitHub 릴리스 업로드까지 한 번에 해요.
macOS 앱은 릴리스가 올라간 뒤 GitHub 이 몇 분 안에 만들어 같은 릴리스에 붙여요. 실패하면 Actions 탭에서 "macOS 앱 만들기"를 릴리스 태그를 넣어 다시 돌리면 돼요.
`--dry-run`을 붙이면 빌드와 서명 확인까지만 하고 아무것도 올리지 않아요. `--no-windows`를 붙이면 Windows 프로그램은 건너뛰어요.
릴리스 설명은 폰의 업데이트 안내에 그대로 보이니 사용자가 읽을 말로 적어 주세요.

### 서명 키 (중요)

폰은 **같은 키로 서명된 APK만** 업데이트로 받아들여요. 다음 두 파일은 저장소에 올라가지 않으니 **따로 백업**하세요.
잃어버리면 기존 사용자는 앱을 지우고 다시 설치해야 해요.

- `android/app/lib-seat-release.jks`
- `android/key.properties`

`tools/signing_cert.sha256`에는 정식 키의 지문이 들어 있어요. 릴리스 스크립트가 이 값과 다른 키로 만든 APK는 올리지 못하게 막아요.

### 글꼴과 라이선스

앱 글꼴은 [Pretendard](https://github.com/orioncactus/pretendard)(SIL Open Font License 1.1)예요. 라이선스 전문은 `assets/licenses/Pretendard-OFL.txt`에 있어요.
알림 아이콘은 Material Icons(Apache License 2.0)의 `event_seat` 모양이에요.

### 앱 아이콘

`assets/icon/`의 원본 이미지로 `dart run flutter_launcher_icons`를 실행하면 안드로이드, Windows, macOS 아이콘이 만들어져요.
적응형 아이콘 앞면은 도구가 안쪽 여백 16%를 자동으로 주는 것을 전제로 크게 그려 두었어요.

### 도면 데이터

좌석 도면은 도서관 홈페이지의 화면 구성을 읽어서 `assets/layouts/rNN.json`으로 만들어 둔 거예요.
사이트가 바뀌면 `python tools/gen_layouts.py`로 다시 만들 수 있어요 (Chrome 또는 Edge 필요).

### 업데이트 경로를 폰 없이 확인

```bash
dart run tools/check_update_live.dart --download
```

실제 GitHub 릴리스를 조회하고 내려받아 크기/해시까지 검증해요.
